# ML-Powered Athlete Card Scores

## Goal
Add ML-derived badges and scores to athlete cards by training a lightweight model offline, exporting per-athlete predictions as JSON, and loading them into the existing card UI.

## What gets built

### 1. Offline ML scorer: `scripts/ml-score-athletes.py`
Trains on `data/ml-dataset.csv` and writes `data/athlete-ml-scores.json`.

Scores produced per athlete (latest available day only):

| Field | Meaning |
|---|---|
| `predicted_up_7d_prob` | Probability raw price is higher 7 days from now (0–1) |
| `volatility_cluster` | `stable`, `momentum`, or `volatile` from K-Means on CV + rolling volatility |
| `deal_score` | 0–100 composite: upside potential vs. current price and liquidity |
| `feature_importance` | Top 3 drivers for this athlete's score (for tooltip) |

Model choices (kept simple and reproducible):
- **Classifier**: scikit-learn `LogisticRegression` or `RandomForestClassifier` for the 7-day direction target already built by `scripts/ml-features.py`.
- **Volatility cluster**: `KMeans(n_clusters=3)` on standardized `raw_cv`, `raw_return_vol_7d`, and `raw_price_chg_7d_pct`.
- **Deal score**: a hand-tuned formula combining predicted probability, recent momentum, listing volume, and stability — no black box.

Validation:
- Uses the same grouped time-series split from the starter notebook.
- Logs accuracy and cluster sizes to stdout so the workflow run is observable.

### 2. Daily automation
Add one step to `.github/workflows/snapshot-history.yml` after the export-ml step:

```text
Run ML athlete scorer
  -> python scripts/ml-score-athletes.py
```

Commit `data/athlete-ml-scores.json` alongside the daily snapshot so card scores stay current.

### 3. React integration

**A. New data hook: `src/hooks/useAthleteMlScores.ts`**
- Fetches `/data/athlete-ml-scores.json` once.
- Provides lookup by athlete name (accent-insensitive fallback).
- Returns `{ scores, loading, error }`.

**B. Update `AthleteCard.tsx`**
- Accept an optional `mlScores` prop.
- Add 1–2 compact badges under the athlete name when scores are available:
  - `🔮 X% Up` — predicted 7-day up probability (only shown if ≥ 0.55, color-coded threshold).
  - `⚡ Momentum` / `🌊 Volatile` / `🛡️ Stable` — volatility cluster badge.
- Add a small "ML Deal Score" bar or numeric pill near the price block (only when `deal_score` is present).
- Clicking/hovering the badge shows a tooltip explaining the score and top feature drivers.

**C. Update `Index.tsx`**
- Load `useAthleteMlScores()` and pass the matching score object into each `AthleteCard`.

Append a short section to `docs/ML-DATASET.md` explaining how `athlete-ml-scores.json` is generated and how to interpret the card badges.

## Out of scope
- No model training inside the browser.
- No real-time inference API.
- No model deployment or hosted backend.
- The first version keeps scores read-only; users cannot tweak model weights in the UI.
